# 가전 수비대 vs 하수구 군단

배수구에서 올라오는 하수구 군단을 가전제품으로 막아 콘센트(기지)를 지키는 웹 타워 디펜스 게임.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 로직 단위 테스트
npm run balance    # 봇 플레이어로 밸런스 확인 (--seed=N: 카드 운 바꾸기, --nocards: 카드 없이, --branches: 갈림길 비교, --endless: 무한 모드, --maps: 맵 비교)
npx vite-node scripts/branches.ts   # 갈래별 떼거리/강적 상황 벤치마크
npx vite-node scripts/units.ts      # 가전별 떼거리/강적 상황 벤치마크 (Lv3 한 대와 Lv4 두 갈래, 1000💰당 효율)
npx vite-node scripts/cc-stack.ts   # 선풍기 여러 대로 적을 영원히 묶을 수 없는지 확인
npm run build      # dist/ 에 배포용 빌드
```

## 플레이 방법

- 오른쪽 상점에서 가전을 고르고 맵을 눌러 설치 (배수관 위에는 설치할 수 없음)
- 설치한 가전을 누르면 업그레이드 / 타겟팅 모드 변경 / 판매(투자금 60% 환불)
- 가전 정보에 ⚔️ DPS(한 적에게 주는 초당 피해, 크리티컬 평균·화상·지금 받는 버프 포함)가 나온다. 업그레이드하면 얼마나 오르는지(→), 갈림길 버튼에는 갈래별 DPS. 범위 공격은 맞은 적마다의 값
- 기지에 도착한 적은 **남은 체력만큼** 기지 HP를 깎는다
- 웨이브 사이 15초 대기 중에 다음 웨이브를 일찍 부르면 남은 시간만큼 보너스
- 20웨이브 보스를 막으면 승리
- 스킬 2개를 웨이브 중에 직접 사용
  - 🪠 뚫어뻥: 누른 곳을 내려쳐 범위 피해 + 기절 (재사용 20초)
  - ⚡ 과부하: 6초 동안 모든 가전 공격 속도 2배 (재사용 40초)
- Lv3 다음은 **갈림길**: 두 갈래 중 하나를 골라 Lv4로 (되돌릴 수 없음)

| 가전 | A (떼거리용) | B (강적용) |
|---|---|---|
| 🍞 토스터 | 🔫 연사 | 🎯 저격 (방어 무시) |
| 🌀 선풍기 | 🌪️ 태풍 (밀어내기) | ❄️ 냉풍 (얼리기, 언 적 피해 +40%) |
| 📦 전자레인지 | ☢️ 해동 폭탄 (불 장판) | 🍳 그릴 (지질수록 최대 4배) |
| 🤖 로봇청소기 | 💨 흡입 (범위 전체) | 🦾 분쇄 (방어 무시) |
| 📶 와이파이 | 📡 5G (버프 강화) | 🛰️ 해킹 (적 약화) |
| 🪙 세탁기 | 🏦 이자 | ⛲ 동전 분수 |

- **특수한 적 4종** (6웨이브부터)
  - 🛡️ 방패병: 방패 4겹. 피해량과 상관없이 한 번 맞을 때마다 한 겹씩 벗겨진다 → 빠른 공격이 유리
  - 👻 유령: 3초마다 1.5초씩 투명해져 조준되지 않는다 → 범위 공격(전자레인지, 선풍기, 뚫어뻥)은 맞는다
  - 💉 치유사: 2초마다 주변 적 체력을 4%씩 회복 (보스 제외) → 먼저 처치
  - 🏃 돌격병: 체력이 절반 이하가 되면 1.5배 빨라진다 → 한 번에 끝내거나 감속
- **특수 웨이브**: 10웨이브부터 5의 배수 웨이브(보스 웨이브 제외)에 판마다 무작위 변칙이 붙고, 한 웨이브 전에 미리보기에 표시된다
  - 🐀 러시(적 수 +50%, 체력 -35%), 🌫️ 안개(사거리 -12%), 💨 폭주(적 속도 +20%), 🪨 강철(방어력 +3), 🥇 황금(보상 2배, 체력 +20%)
- **🏆 업적 16개**: 시작 화면의 업적 버튼에서 확인. 달성하면 알림이 뜨고 부품(🔩)을 받는다 (부품은 나중에 뽑기에 사용 예정). 목록은 `src/achievements.ts`
- **🎰 뽑기와 🎒 덱 편성** (시작 화면 오른쪽 버튼)
  - 부품(🔩)은 웨이브를 깰 때마다(웨이브당 5 × 난이도 배율), 20웨이브 승리(+50), 업적으로 모은다
  - 뽑기: 1회 100, 10회 900. 희귀 70% / 영웅 25% / 전설 5%, 30회 안에 전설 확정, 중복은 부품으로 환급
  - 새 가전 6종: 🔥 가스레인지(화상), ⚡ 멀티탭(튕기는 번개), 🔋 보조배터리(공격력 버프), 👔 다리미(방어력 깎기), ❄️ 에어컨(전체 감속), 🚿 식기세척기(일직선 관통)
  - 새 가전도 Lv3 다음에 갈림길이 있다

    | 가전 | A (떼거리용) | B (강적용) |
    |---|---|---|
    | 🔥 가스레인지 | 🌋 화염 방사 (주변 전체 화상) | 🍲 압력솥 (아주 센 화상) |
    | ⚡ 멀티탭 | 🌩️ 과전류 (10마리 튕김) | 🔌 고압선 (강한 번개, 방어 무시) |
    | 🔋 보조배터리 | 🔆 대용량 (넓은 범위 +50%) | 💥 과충전 (좁은 범위 +90%) |
    | 👔 다리미 | 💨 스팀 (관통 + 방어 깎기) | 🗜️ 프레스 (강한 한 방, 방어 -6) |
    | ❄️ 에어컨 | 🧊 급냉 (전체 감속 45%) | 💧 제습 (감속 35% + 받는 피해 +25%) |
    | 🚿 식기세척기 | 🌊 고압 세척 (굵은 물줄기) | 🧪 살균 (한 마리 집중, 방어 무시) |
  - 덱: 가진 가전 중 최대 6종을 골라 들고 간다. 기존 6종은 처음부터 보유
  - 로직은 `src/gacha.ts`, 가전 수치는 `src/data/units.ts`
- **🃏 보상 카드**: 3웨이브마다 카드 3장 중 1장을 고른다 (건너뛰면 💰50). 판마다 무작위로 나와서 전략이 달라진다
  - 일반 11장, 희귀 7장, 위험 5장(좋은 효과 + 나쁜 효과), 전설 6장(규칙을 바꿈)
  - 수치형 카드는 3번까지 겹치고, 고른 카드는 일시정지 화면에서 볼 수 있다
  - 카드 목록은 `src/data/cards.ts`, 이름과 설명은 `src/strings.ko.ts`
- 공격의 10%는 크리티컬(2.5배)
- **맵 5개** (시작 화면에서 선택, 기록은 맵별로 따로)
  - 🍳 주방: 길게 굽이치는 배수관 하나
  - 🛁 욕실: 위아래 배수구 두 곳에서 나와 가운데서 합류
  - 🪴 베란다: 길은 길지만 화분·빨래 바구니 때문에 설치 자리가 귀함
  - 🌀 세탁실: 바깥에서 안쪽으로 도는 긴 나선, 콘센트는 한가운데. 안쪽 자리는 여러 바퀴를 한꺼번에 덮는 명당 (적 체력 ×1.45)
  - 🛋️ 거실: 배수관이 세 번 엇갈린다. 교차점 근처 가전은 같은 적을 두 번 만난다 (적 체력 ×1.5)
- **♾️ 무한 모드**: 시작 화면에서 켜거나, 20웨이브 승리 후 '계속 버티기'. 21웨이브부터 자동 생성, 10웨이브마다 보스가 늘어남. 기록은 따로 저장
- ⏸️ 버튼이나 Esc/P 키로 일시정지 (계속하기 / 처음부터 / 나가기). 탭을 벗어나면 자동 일시정지
- 상단에 다음 웨이브 구성 미리보기, 🔊 버튼으로 효과음 끄기
- 미리보기 아래 줄에 다음에 깰 웨이브의 보상(💰 클리어 보너스 + 🪙 세탁기 수입, 🔩 부품)이 표시된다. 웨이브 중에는 지금 웨이브 기준이고, 이자 세탁기 수입은 지금 보유금으로 계산한 추정치
- 웨이브를 깨면 배너에 실제로 얻은 코인·부품 합계가, 아래 알림에 보너스·세탁기·부품 내역이 뜬다

| 가전 | 역할 |
|---|---|
| 🍞 토스터 | 원거리 단일 공격 |
| 🌀 선풍기 | 범위 감속 |
| 📦 전자레인지 | 범위 폭발 |
| 🤖 로봇청소기 | 근거리 고속 공격 |
| 📶 와이파이 | 주변 가전 공격 속도 증가 |
| 🪙 동전 세탁기 | 웨이브마다 수입 (최대 3대) |

## 구조

```
src/core/      게임 로직 (Phaser 의존 없음, 테스트 대상, 멀티플레이 서버에서도 재사용 가능)
  game.ts      상태, 명령(Command) 처리, 시뮬레이션 스텝
  path.ts      경로 계산
  types.ts
src/data/      밸런스 데이터: units.ts, enemies.ts, waves.ts, map.ts(맵 3개), difficulty.ts, abilities.ts
src/config.ts  시작 자금, 기지 HP, 보너스 등 규칙 수치
src/strings.ko.ts  화면 텍스트 (다른 언어는 같은 키로 파일 추가)
src/scenes/    Phaser 렌더링과 입력
tests/         Vitest
scripts/       balance.ts (밸런스 시뮬레이터), branches.ts (갈래 벤치마크), shot.cjs (Playwright 스크린샷)
```

유저 조작은 모두 `game.apply(command)`를 거친다. 멀티플레이를 붙일 때는 이 명령을 서버로 보내고, 서버가 같은 `Game`을 돌리면 된다.

## 그래픽 바꾸기

그림은 `public/sprites/`에 있고, 목록은 `src/sprites.ts`에 있다. 지금 그림은 모두 직접 그린 SVG다.

- **같은 이름의 파일로 덮어쓰면** 그 그림이 바뀐다 (예: `public/sprites/toaster.svg`)
- **PNG를 쓰려면** `toaster.png`를 넣고 `src/sprites.ts`에서 `toaster: 'toaster.png'`로 고친다
- 권장 규격: 정사각형, 256×256 이상, 배경 투명, 캐릭터가 가운데를 꽉 채우게
- 파일이 없거나 깨져 있으면 그 그림만 이모지로 그려지고 게임은 정상 동작한다

| 파일 이름 | 대상 |
|---|---|
| `toaster` `fan` `microwave` `vacuum` `wifi` `washer` | 가전 6종 |
| `goo` `rat` `grease` `roach` `splitter` `splitling` `boss` | 하수구 군단 7종 |
| `outlet` `drain` | 기지(콘센트), 배수구 |
| `proj_toast` `proj_fire` | 투사체 (식빵, 불꽃) |
| `ob_bathtub` `ob_plant` `ob_basket` `ob_shirt` | 장애물 |
| `ab_plunger` `ab_overload` | 스킬 아이콘 |
