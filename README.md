# 가전 수비대 vs 하수구 군단

배수구에서 올라오는 하수구 군단을 가전제품으로 막아 콘센트(기지)를 지키는 웹 타워 디펜스 게임.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 로직 단위 테스트
npm run balance    # 봇 플레이어로 밸런스 확인 (--seed=N: 카드 운 바꾸기, --nocards: 카드 없이, --branches: 갈림길 비교, --endless: 무한 모드, --maps: 맵 비교)
npx vite-node scripts/branches.ts   # 갈래별 떼거리/강적 상황 벤치마크
npx vite-node scripts/units.ts      # 가전별 떼거리/강적 상황 벤치마크 (Lv3 한 대와 Lv4 두 갈래, 1000💰당 효율)
npx vite-node scripts/cc-stack.ts   # 선풍기 여러 대 + 에어컨으로 느린 적·보스를 영원히 묶을 수 없는지 확인
npm run build      # dist/ 에 배포용 빌드
npx vite --port 5199 & node scripts/render3d.cjs   # 3D 캐릭터(scripts/art3d/models.ts)를 public/sprites/*.png로 렌더링
```

## 플레이 방법

- 오른쪽 상점에서 가전을 고르고 맵을 눌러 설치 (배수관 위에는 설치할 수 없음). 놓은 뒤에도 설치 모드가 이어져 계속 놓을 수 있고, Esc·우클릭으로 끝
- 설치한 가전을 누르면 업그레이드 / 타겟팅 모드 변경 / 판매(투자금 60% 환불). '모두' 버튼은 고른 가전과 **종류도 갈래도 같은** 가전을 싼 것부터 돈이 되는 만큼 함께 올린다: 갈래 전(Lv1~3)이면 Lv3까지, 같은 갈래끼리는 ★강화. 갈림길은 대신 골라 주지 않으니 가전마다 직접 고른다 (`src/core/bulk.ts`)
- 3D 맵: 마우스 휠·두 손가락으로 확대·축소, 끌어서 이동, '🔍 전체 보기'로 원래대로
- 가전 정보에 ⚔️ DPS(한 적에게 주는 초당 피해, 크리티컬 평균·화상·지금 받는 버프 포함)가 나온다. 업그레이드하면 얼마나 오르는지(→), 갈림길 버튼에는 갈래별 DPS. 범위 공격은 맞은 적마다의 값
- 기지에 도착한 적은 **남은 체력만큼** 기지 HP를 깎는다
- 웨이브 사이 15초 대기 중에 다음 웨이브를 일찍 부르면 남은 시간만큼 보너스
- 20웨이브 보스를 막으면 승리
- 스킬 2개를 웨이브 중에 직접 사용
  - 🪠 뚫어뻥: 누른 곳을 내려쳐 범위 피해 + 기절 (재사용 20초)
  - ⚡ 과부하: 6초 동안 모든 가전 공격 속도 2배 (재사용 40초)
- 감속은 겹쳐도 원래 속도의 35%(보스 50%) 아래로 내려가지 않고, 태풍 선풍기의 밀어내기는 같은 적을 밀 때마다 절반으로 줄어든다 (느린 적이 갇히지 않게)
- Lv3 다음은 **갈림길**: 두 갈래 중 하나를 골라 Lv4로 (되돌릴 수 없음)
- Lv4 다음은 **★강화** 최대 10번: 별 하나당 공격력·화상·수입 +25%, 지원 효과 +10% (와이파이 공속·해킹, 보조배터리, 에어컨 전체 감속·제습, 선풍기 감속 지속·밀어내기·얼리기, 동전 분수 보상). 한도에 닿아 더 오르지 않으면 강화가 거기서 멈춘다 (급냉 에어컨은 ★4에서 전체 감속 60% 한도). 정보 창에 ★강화 전후 수치(→)가 나온다, 비용은 갈래 비용 × 1.5ⁿ. 후반에 가전을 끝없이 늘리지 않고 남는 돈을 쓸 수 있다

| 가전 | A (떼거리용) | B (강적용) |
|---|---|---|
| 🍞 토스터 | 🔫 연사 | 🎯 저격 (방어 무시) |
| 🌀 선풍기 | 🌪️ 태풍 (밀어내기) | ❄️ 냉풍 (얼리기, 언 적 피해 +40%) |
| 📦 전자레인지 | ☢️ 해동 폭탄 (불 장판) | 🍳 그릴 (지질수록 최대 4배) |
| 🤖 로봇청소기 | 💨 흡입 (범위 전체) | 🦾 분쇄 (방어 무시) |
| 📶 와이파이 | 📡 5G (버프 강화) | 🛰️ 해킹 (적 약화) |
| 🪙 세탁기 | 🏦 이자 | ⛲ 동전 분수 |

- **특수한 적 5종** (6웨이브부터)
  - 🛡️ 방패병: 방패 4겹. 피해량과 상관없이 한 번 맞을 때마다 한 겹씩 벗겨진다 → 빠른 공격이 유리
  - 👻 유령: 3초마다 1.5초씩 투명해져 조준되지 않는다 → 범위 공격(전자레인지, 선풍기, 뚫어뻥)은 맞는다
  - 💉 치유사: 2초마다 주변 적 체력을 4%씩 회복 (보스·다른 치유사 제외). 치유사가 여럿이어도 회복은 겹치지 않는다 → 먼저 처치
  - 🤷 식스세븐 (7웨이브부터): 손바닥 위 6과 7을 저울질하며 걷다가 6.7초마다 하나를 고른다. 6이면 단단(방어 +6, 느림), 7이면 빠름(속도 ×1.7, 방어 0). 고른 숫자가 커지고 빛난다
  - 🏃 돌격병: 체력이 절반 이하가 되면 1.5배 빨라진다 → 한 번에 끝내거나 감속
- **67 이스터에그**: 한 판에서 67·167·267…번째 처치마다 💰67, 무한 모드 67웨이브 — 화면 가운데에 파란 6·빨간 7이 번갈아 오르내리는 큰 67이 뜬다, 식스세븐 67마리 처치 업적(부품 67)
- **보스 2종**
  - 👹 막힌 배수구 대왕 (20웨이브): 단단하고 고무 슬라임을 불러낸다
  - 🕺 「L을 가져가!」 (15웨이브 중간 보스): 춤추며 박자마다 빨라졌다 느려졌다 하고, 8초마다 이마에 L을 대고 화면 가운데 크게 "L을 가져가!"를 띄우며 반경 안 가전을 약 올린다 (💢 3초간 공격 속도 -40%). 무한 모드에서는 10웨이브마다 대왕과 번갈아 나온다
- **특수 웨이브**: 10웨이브부터 5의 배수 웨이브(보스 웨이브 제외)에 판마다 무작위 변칙이 붙고, 한 웨이브 전에 미리보기에 표시된다
  - 🐀 러시(적 수 +50%, 체력 -35%), 🌫️ 안개(사거리 -12%), 💨 폭주(적 속도 +20%), 🪨 강철(방어력 +3), 🥇 황금(보상 2배, 체력 +20%)
- **📖 몬스터 도감과 소개 카드**: 처음 보는 몬스터가 나오면 게임이 잠깐 멈추고 소개 카드(그림, 특징, 체력·속도·방어, 대응 팁)가 뜬다. 한 번 본 몬스터는 다시 안 뜨고 도감에 기록된다. 시작 화면 '📖 도감'에서 만난 몬스터는 자세히, 못 만난 몬스터는 실루엣과 ???로 보인다 (처음 등장 웨이브, 누적 처치 수). 설명 문구는 `STR.enemies`, 순서는 `src/bestiary.ts`
- **🕺 움직이는 도감 그림**: 「L을 가져가!」(L 포즈 → 옆차기 춤)와 식스세븐(6·7 저울질)은 도감과 소개 카드에서 움직인다. 3D 모델을 프레임별로 렌더링한 스프라이트 시트(`public/sprites/<이름>_anim.png`, 정의는 `src/view3d/anims.ts`의 `MODEL_ANIMS`)는 `scripts/render3d.cjs`가 다른 그림과 함께 만든다.
- **🔌 가전 도감**: 도감의 '가전 수비대' 탭에서 가전 12종을 본다. 가진 가전은 역할, 레벨별 DPS(또는 지원 효과)·사거리·비용, Lv4 갈림길, 설치 횟수를, 못 뽑은 가전은 실루엣과 등급을 보여 준다.
- **🏅 무한 모드 랭킹**: 무한 모드 판이 끝나면(또는 그만두면) 기록이 남는다. 시작 화면 '🏅 무한 랭킹'에서 '📱 내 기기'(이 기기의 난이도별 상위 10개)와 '🌐 온라인'(전 세계, 난이도마다 한 사람당 최고 기록 하나) 표를 보고, 이름(최대 8글자, 안 정하면 '수비대1234')을 바꿀 수 있다. 끝 화면에 내 기기 순위와 온라인 순위가 나온다. 기록 모양과 순위 규칙은 `src/ranking.ts`, 온라인은 `src/online/` (Firebase를 처음 쓸 때만 불러온다)
- **📱 휴대폰 성능**: 같은 모양의 3D 부품(구·상자 등)은 한 번만 만들어 함께 쓰고, 게임 화면에서는 곡면을 절반 정도로 나눈다. 사라진 적의 모형은 버리지 않고 다음 적이 다시 쓴다. 3초 평균이 40fps 아래면 품질을 자동으로 낮춘다 (1단계: 적 그림자 끔·해상도 1.5배, 2단계: 보스 외 적은 그림 판·해상도 1배). 터치 기기는 1단계로 시작 (`QUALITY`, `src/view3d/board.ts`)
- 3D 렌더러(WebGL 컨텍스트)는 판이 바뀌어도 하나를 다시 쓴다. 판마다 새로 만들면 브라우저 한도(약 16개)를 넘을 때 Phaser 화면이 끊겨 3D 맵만 남는 버그가 있었다
- **🏆 업적 17개**: 시작 화면의 업적 버튼에서 확인. 달성하면 알림이 뜨고 부품(🔩)을 받는다 (부품은 뽑기에 쓴다). 목록은 `src/achievements.ts`
- **🎰 뽑기와 🎒 덱 편성** (시작 화면 오른쪽 버튼)
  - 부품(🔩)은 웨이브를 깰 때마다(웨이브당 5 × 난이도 배율), 20웨이브 승리(+50), 업적으로 모은다
  - 뽑기: 1회 100, 10회 900. 희귀 70% / 영웅 25% / 전설 5%, 30회 안에 전설 확정, 중복은 부품으로 환급
  - 새 가전 6종: 🔥 가스레인지(화상), ⚡ 멀티탭(튕기는 번개), 🔋 보조배터리(공격력 버프), 👔 다리미(방어력 깎기), ❄️ 에어컨(전체 감속), 🚿 식기세척기(일직선 관통)
  - 새 가전도 Lv3 다음에 갈림길이 있다

    | 가전 | A (떼거리용) | B (강적용) |
    |---|---|---|
    | 🔥 가스레인지 | 🌋 화염 방사 (주변 전체 화상) | 🍲 압력솥 (아주 센 화상) |
    | ⚡ 멀티탭 | 🌩️ 과전류 (10마리 튕김) | 🔌 고압선 (강한 번개, 방어 무시) |
    | 🔋 보조배터리 | 🔆 대용량 (넓은 범위 +50%) | 💥 과충전 (좁은 범위 +90%) |
    | 👔 다리미 | 💨 스팀 (관통 + 방어 깎기) | 🗜️ 프레스 (강한 한 방, 방어 -6) |
    | ❄️ 에어컨 | 🧊 급냉 (전체 감속 45%) | 💧 제습 (감속 35% + 받는 피해 +25%) |
    | 🚿 식기세척기 | 🌊 고압 세척 (굵은 물줄기) | 🧪 살균 (한 마리 집중, 방어 무시) |
  - 덱: 가진 가전 중 최대 6종을 골라 들고 간다. 기존 6종은 처음부터 보유
  - 로직은 `src/gacha.ts`, 가전 수치는 `src/data/units.ts`
- **🚧 판 밖 성장 (지금은 꺼 둠)**: 아래 숙련도와 연구는 코드에 있지만 `src/meta.ts`의 `META.enabled = false`로 꺼져 있다. 화면에 안 보이고 판에도 반영되지 않는다. 올린 상태의 난이도와 랭킹 영향을 확인한 뒤 `true`로 바꿔서 연다 (켜면 뽑기 중복이 숙련도 +1로 바뀐다)
- **⭐ 가전 숙련도** (덱 편성 화면): 가전마다 부품으로 올리는 영구 강화, 최대 5레벨 (비용 40 → 70 → 110 → 160 → 220). 레벨당 공격력·화상·수입 +4%, 지원형(와이파이·보조배터리·에어컨)은 효과 +2%. 판 안의 ★강화와 곱해진다. 사거리·공격 속도는 그대로
- **🔬 연구** (시작 화면): 부품으로 올리는 영구 강화. 비상금(시작 자금 +25 ×4), 튼튼한 콘센트(기지 HP +5% ×4), 뚫어뻥 손잡이·차단기 증설(스킬 대기시간 -5% ×3), 중고 장터(판매 환불 +5%p ×2), 카드 수집가(다시 뽑기 비용 -20 ×2), 넓은 안목(카드 4장 중에 고르기)
  - 연구·숙련도 로직은 `src/meta.ts` (`applyMeta`가 한 판의 설정에 반영). 무한 모드 랭킹에도 그대로 적용된다
- **🃏 보상 카드**: 3웨이브마다 카드 3장 중 1장을 고른다 (건너뛰면 💰50). 판마다 무작위로 나와서 전략이 달라진다
  - 일반 17장, 희귀 11장, 위험 6장(좋은 효과 + 나쁜 효과), 전설 7장(규칙을 바꿈)
  - **덱에 맞는 카드만 나온다**: 가전 전용 카드(바삭한 식빵, 파란 불꽃 등)는 그 가전이 덱에 있을 때만 후보가 된다
  - **🎲 다시 뽑기**: 💰60을 내고 내민 카드를 새로 뽑는다 (카드 고르기마다 한 번, 방금 본 카드는 안 나옴)
  - 규칙을 바꾸는 카드: 🧨 발화(크리티컬이 화상을 건다), 🍯 끈끈이 보상(감속·기절 중 처치 💰+2), 🔁 보상 판매(판 뒤 다음 설치 반값), 🥊 선제 공격(체력이 가득한 적에게 +40%), 🪓 마무리 일격(체력 12% 이하 즉시 처치, 보스 제외)
  - 수치형 카드는 3번까지 겹치고, 고른 카드는 일시정지 화면에서 볼 수 있다
  - 카드 목록은 `src/data/cards.ts`, 이름과 설명은 `src/strings.ko.ts`
- 공격의 10%는 크리티컬(2.5배)
- **맵 5개** (시작 화면에서 선택, 기록은 맵별로 따로)
  - 🍳 주방: 길게 굽이치는 배수관 하나. **3D 화면**: 조리대 위 디오라마, 원근 카메라, 나무 도마 고지대(장식), 허브 화분·책 더미 같은 소품 칸(설치 불가), 보드 둘레 주방 소품
  - 🛁 욕실: 위아래 배수구 두 곳에서 나와 가운데서 합류. 큰 욕조(6×4칸), 고무 오리·샴푸·칫솔 컵, 분홍 수건 고지대 (적 체력 ×1.2)
  - 🪴 베란다: 길은 길지만 화단·빨래 바구니·옷 더미 때문에 설치 자리가 귀함. 하늘과 난간, 벽돌 화단 고지대
  - 🌀 세탁실: 바깥에서 안쪽으로 도는 긴 나선, 콘센트는 한가운데. 안쪽 자리는 여러 바퀴를 한꺼번에 덮는 명당 대형 세탁기·건조기 (적 체력 ×1.6)
  - 🛋️ 거실: 배수관이 세 번 엇갈린다. 교차점 근처 가전은 같은 적을 두 번 만난다. 소파·TV·책장, 쿠션 고지대 (적 체력 ×1.75)
- **♾️ 무한 모드**: 시작 화면에서 켜거나, 20웨이브 승리 후 '계속 버티기'. 21웨이브부터 자동 생성, 10웨이브마다 보스가 늘어남. 기록은 따로 저장
- **🌐 언어 5개**: 한국어, English, 简体中文, 日本語, Tagalog. 시작 화면 오른쪽 '⚙️ 설정'에서 고른다 (효과음 켜고 끄기도 여기). 처음에는 브라우저 언어를 따르고, 지원하지 않는 언어면 영어
  - 문구는 `src/strings.<언어>.ts`, 한국어(`strings.ko.ts`)가 기준이고 나머지는 `Strings` 타입으로 같은 키를 맞춘다. 화면 코드는 `src/i18n.ts`의 `STR`을 쓴다
  - 새 언어 추가: `strings.<언어>.ts`를 만들고 `src/i18n.ts`의 `STRINGS`·`LANGS`에 한 줄씩. `tests/i18n.test.ts`가 빠진 키와 번역 안 된 한글을 잡는다
  - 글꼴 '주아'에는 한글·영문만 있어서 일본어·중국어는 기기 글꼴로 그린다
- ⏸️ 버튼이나 Esc/P 키로 일시정지 (계속하기 / 처음부터 / 나가기). 탭을 벗어나면 자동 일시정지
- 상단에 다음 웨이브 구성 미리보기, 🔊 버튼으로 효과음 끄기
- 미리보기 아래 줄에 다음에 깰 웨이브의 보상(💰 클리어 보너스 + 🪙 세탁기 수입, 🔩 부품)이 표시된다. 웨이브 중에는 지금 웨이브 기준이고, 이자 세탁기 수입은 지금 보유금으로 계산한 추정치
- 웨이브를 깨면 배너에 실제로 얻은 코인·부품 합계가, 아래 알림에 보너스·세탁기·부품 내역이 뜬다

## 구조

```
src/core/      게임 로직 (Phaser 의존 없음, 테스트 대상, 멀티플레이 서버에서도 재사용 가능)
  game.ts      상태, 명령(Command) 처리, 시뮬레이션 스텝
  path.ts      경로 계산
  types.ts
src/data/      밸런스 데이터: units.ts, enemies.ts, waves.ts, map.ts(맵 5개, 주방은 52px 격자), difficulty.ts, abilities.ts
src/config.ts  시작 자금, 기지 HP, 보너스 등 규칙 수치
src/strings.<언어>.ts  화면 텍스트 (ko 기준, en·zh·ja·tl). 고르는 곳은 src/i18n.ts
src/scenes/    Phaser 렌더링과 입력 (UI, 이펙트, 2D 맵)
src/view3d/    three.js 3D 화면 (격자 맵): board.ts(보드·카메라·캐릭터), models.ts(2등신 캐릭터), props.ts(소품), kit.ts(부품)
tests/         Vitest
scripts/       balance.ts (밸런스 시뮬레이터), branches.ts (갈래 벤치마크), shot.cjs (Playwright 스크린샷)
               render3d.cjs + art3d/ (3D 모델을 PNG로 렌더링, 보드 시안 diorama.html)
```

유저 조작은 모두 `game.apply(command)`를 거친다. 멀티플레이를 붙일 때는 이 명령을 서버로 보내고, 서버가 같은 `Game`을 돌리면 된다.

## 3D 화면

맵 5개 모두 격자(`grid`) 위에 있고 three.js로 3D 보드를 그린다. 맵별 분위기(타일·고지대 색, 받침, 뒤 배경, 둘레 장식)는 `src/view3d/themes.ts`.

- Phaser 캔버스를 투명하게 두고 그 뒤에 three.js 캔버스를 깐다. UI·이펙트·숫자는 Phaser, 보드·캐릭터·바닥 표시(사거리, 배치 칸, 후광)는 three.js
- 카메라는 원근 카메라(`makeCamera`). 게임 좌표 ↔ 화면 좌표는 `Board3D.project / unproject`로 바꾼다
- 게임 규칙(`src/core`)은 3D와 상관없다. 고지대는 보기만 다르고, 소품 칸은 `blocked`로 설치 불가
- 캐릭터 23종 모두 2등신 3D 모델(`src/view3d/models.ts`). 가전은 공통으로 **전원 플러그 꼬리**가 있고, 플러그가 레벨 색으로 빛난다 (Lv1 하양, Lv2 초록, Lv3 금색, Lv4 보라). 업그레이드하면 튀어 오르며 플러그가 번쩍인다
- 상점 아이콘과 2D 맵 그림(`public/sprites/*.png`)도 같은 모델을 렌더링한 것 (`node scripts/render3d.cjs`)
- 모델이 없는 키는 그림을 세운 판(빌보드)으로 대신 그린다
- WebGL을 못 쓰면 2D 타일 화면으로 대신 그린다

## 그래픽 바꾸기

그림은 `public/sprites/`에 있고, 목록은 `src/sprites.ts`에 있다. 지금 그림은 모두 직접 그린 SVG다.

- **같은 이름의 파일로 덮어쓰면** 그 그림이 바뀐다 (예: `public/sprites/toaster.svg`)
- **PNG를 쓰려면** `toaster.png`를 넣고 `src/sprites.ts`에서 `toaster: 'toaster.png'`로 고친다
- 권장 규격: 정사각형, 256×256 이상, 배경 투명, 캐릭터가 가운데를 꽉 채우게
- 파일이 없거나 깨져 있으면 그 그림만 이모지로 그려지고 게임은 정상 동작한다

| 파일 이름 | 대상 |
|---|---|
| `toaster` `fan` `microwave` `vacuum` `wifi` `washer` | 가전 6종 |
| `goo` `rat` `grease` `roach` `splitter` `splitling` `boss` | 하수구 군단 7종 |
| `outlet` `drain` | 기지(콘센트), 배수구 |
| `proj_toast` `proj_fire` | 투사체 (식빵, 불꽃) |
| `ob_bathtub` `ob_plant` `ob_basket` `ob_shirt` | 장애물 |
| `ab_plunger` `ab_overload` | 스킬 아이콘 |

## 🌐 온라인 랭킹 (Firebase) 연결하기

설정이 없으면 온라인 탭은 "준비 중"으로 나오고 게임은 그대로 동작한다.

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트를 만든다 (Google 애널리틱스는 꺼도 된다)
2. **Authentication → 시작하기 → 로그인 방법 → 익명** 사용 설정
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드, 가까운 위치 예: `asia-northeast3` 서울)
4. **프로젝트 설정 → 일반 → 내 앱 → 웹 앱(</>) 추가** 후 나오는 `firebaseConfig` 값을 복사
5. GitHub 저장소 **Settings → Secrets and variables → Actions → Variables** 에 `FIREBASE_CONFIG` 변수를 만들고 4번 값을 붙여 넣는다 (`const firebaseConfig = {...}` 모양 그대로도, JSON도 된다). 웹 앱 설정은 비밀이 아니라 공개돼도 괜찮다 — 실제 보호는 보안 규칙이 한다
6. 보안 규칙과 색인을 올린다 (내 컴퓨터에서 한 번):
   ```bash
   npx firebase login
   npx firebase deploy --only firestore --project <프로젝트 ID>
   ```
7. **Authentication → 설정 → 승인된 도메인**에 `<사용자>.github.io` 추가
8. main에 머지(또는 Actions에서 다시 실행)하면 온라인 랭킹이 켜진 채로 배포된다

로컬에서 Firebase 없이 시험하기: `npm run emulators`로 에뮬레이터를 띄우고 `.env.local`에
`VITE_FIREBASE_EMULATOR=1`, `VITE_FIREBASE_CONFIG={"apiKey":"demo","projectId":"demo-defense","appId":"demo"}`를 넣고 `npm run dev`.

**보안 규칙** (`firestore.rules`, 테스트 `npm run test:rules` — Java 필요, CI에서도 돈다):
- 누구나 읽기, 쓰기는 익명 로그인한 본인 문서(`<uid>_<난이도>`)만, 지우기 금지
- 더 좋은 기록(웨이브가 높거나, 같으면 처치 수가 많을 때)일 때만 덮어쓰기, 이름만 바꾸기는 허용
- 값 검사: 이름 1~8글자, 웨이브 1~500, 처치 수 ≤ 웨이브×150, 맵·난이도는 정해진 값, 시각은 서버 시각
- 한계: 게임 계산이 브라우저에서 돌아서 마음먹고 조작한 기록까지 완전히 막지는 못한다. 문제가 생기면 Firebase App Check를 켜거나 콘솔에서 해당 문서를 지운다
